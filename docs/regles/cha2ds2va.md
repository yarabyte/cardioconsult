# Règle cha2ds2va

- **Objectif** : score CHA₂DS₂-VA (sans critère sexe) pour documentation.
- **Population** : patients avec FA/flutter dans le contexte.
- **Entrées** : date de naissance, date de l'acte, critères TriState.
- **Formule** : âge dérivé à la date de l'acte ; inconnus → intervalle min–max.
- **Source** : référentiel cabinet — à valider cliniquement.
- **Version** : 1.0
- **Validation clinique** : à renseigner par un cardiologue.
