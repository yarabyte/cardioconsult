# Règle AO-ASC-01

- **Objectif** : niveaux d'alerte de mesure aortique **par segment**.
- **Niveaux** : non_renseigne, sous_seuil, alerte_mesure, discussion_specialisee, potentiellement_urgent.
- **Croissance** : uniquement si mesure antérieure datée.
- **Surface/hauteur** : taille obligatoire (AO-AREA-HEIGHT).
- **Version** : 0.1 — seuils configurables, à valider cliniquement.
- **Interdit** : aucune décision chirurgicale automatisée.
