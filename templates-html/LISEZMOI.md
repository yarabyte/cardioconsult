# CardioConsult — templates HTML (v1, 23/11/2026)

- Ouvrir `index.html` dans Chrome, Edge, Firefox ou Safari : aucun serveur nécessaire. La police se charge depuis Google Fonts si une connexion est disponible.
- 19 écrans autonomes. La navigation latérale relie les écrans entre eux et le bouton « Tous les écrans » ramène à l'index.
- Les interactions sont fonctionnelles : filtres, scores, validation du sous-domaine, MFA, ordonnance, lits, matrice des permissions, etc.
- Données 100 % fictives.
- `assets/` : logos SVG et favicons.
- `PROMPT_CURSOR.md` : prompt de conversion vers Next.js + Tailwind + shadcn/ui. Copier ce dossier sous `templates-html/` à la racine du nouveau dépôt avant de lancer Cursor.
